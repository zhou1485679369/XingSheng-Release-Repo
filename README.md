# 形声数字人工作室

**形声**是一款在自己电脑上运行的数字人视频制作工具。选择人物形象和声音后，可以把讲稿生成口播视频、制作逐轮问答视频，或让数字人按页讲解演示文稿。它提供素材库、项目草稿、任务进度和历史视频管理，生成的视频可预览并下载为 MP4。

目前提供 **Windows 11 x64 安装包**。软件界面和本机服务在电脑上运行；选择云端模式时，相关请求会发送到你配置的云端服务。

## 下载安装

1. 前往 [Releases](https://github.com/zhou1485679369/XingSheng-Release-Repo/releases/latest) 下载 `XingSheng-0.1.2-win-x64.exe`，双击安装并启动。安装包未进行代码签名，Windows 可能提示“未知发布者”。
2. 打开左侧 **模型配置**，点击 **下载并安装基础模型**。模型权重不在安装包里；第一次下载需要联网，并建议预留至少 10 GB 可用空间。页面会显示当前阶段和安装日志。
3. 页面提示安装完成后，退出并重新打开形声。部分语音识别或声音模型会在首次使用相应功能时继续下载；在它们下载完之前，不能保证完全离线运行。
4. 在 **模型配置** 中查看每类模型的状态。只有显示“已安装”的选项才能切换使用。

安装应用后，无需另装 Docker、Node.js 或 Python。视频生成在本机执行，CPU 推理可能比较慢；生成速度取决于电脑配置、所选模型、讲稿长度和导出分辨率。

## 可以做什么

| 功能 | 使用方式 |
| --- | --- |
| **数字人口播** | 输入讲稿，选择人物、声音、背景和画面比例，先试听声音，再点击“生成口播视频”。 |
| **数字人对话** | “逐轮生成视频”支持文字或录音提问，生成回答和对应视频；“实时语音对话”支持麦克风问答和打断回答。默认显示静态人物画面；安装 SadTalker 后可选逐轮口型视频，但每轮需等待渲染，**不提供视频通话式实时口型**。 |
| **讲解 PPT** | 导入 PPT、PPTX 或 PDF，检查每页内容，编辑或生成逐页讲稿，再导出讲解视频。**Windows 导入 PPT/PPTX 需要电脑安装 Microsoft PowerPoint**；PDF 可直接导入。 |
| **素材库** | 使用内置形象和声音，或上传已获授权的单人正面照片、参考录音、背景图片和背景音乐。照片会保存原貌版本，并生成一个风格化版本。 |
| **批量制作与项目** | 批量提交内容，保存讲稿及制作设置为项目草稿，之后继续编辑。 |
| **历史视频** | 预览生成视频的首帧和成片、下载 MP4、以历史配置新建项目，或删除历史记录及其生成文件。 |

视频可以设置横屏 16:9、竖屏 9:16 或方形 1:1，选择人物位置、背景、字幕和音乐。在 **设置 → 视频导出** 中可以选择 480p 至 4K 分辨率、24/25/30 fps 和画质。高分辨率会增加导出时间与文件大小；放大原始人物画面不会增加真实细节。

## 第一次生成口播视频

1. 确认基础模型已安装，进入 **数字人口播**。
2. 输入讲稿；在右侧选择人物形象和声音。需要时更换背景、比例、版式、字幕或背景音乐。
3. 点击 **先试听讲稿** 检查声音，再点击 **生成口播视频**。
4. 在页面下方查看任务进度。完成后可在预览区播放，或到 **历史视频** 下载 MP4；运行中的任务可以点击 **停止**。

上传真人照片或录音时，界面会要求确认你拥有该人物形象或声音的使用授权。自定义克隆音色只在本地模式使用；不同云端语音服务不一定支持该音色。

## 本地模式、云端模式与访问码

- **本地模式**使用安装在电脑上的模型；首次下载完成后，具体功能能否离线使用取决于该功能所需模型是否已下载齐全。
- **云端模式**需要先到 **设置**，分别配置对话、语音识别、语音合成或图片编辑所需的接口和密钥。只填写某一类接口不会自动启用其他云端能力。数字人视频驱动仍在本机执行。
- 每次部署可试用**成功生成的 3 个视频**。试用结束后，输入交付方提供的访问码继续使用；删除历史视频不会恢复试用次数。
